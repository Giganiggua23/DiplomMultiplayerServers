# Unity Multiplayer Server System For Survival Games

Серверная система для многопользовательской игры в проектах жанра survival на базе Unity, сетевого фреймворка Mirror и облачной базы данных Firebase Realtime Database. Проект реализует автоматический запуск выделенного сервера, передачу данных о сервере в облако и клиентский интерфейс списка доступных серверов, а так же базовые механики характерные данному жанру игры.



======

## Стек технологий

* **Unity** 6000.0.56f1+
* **Mirror** — сетевой фреймворк версии 96.0.1 +
* **Firebase Realtime Database** — облачное хранилище данных для серверов от  майкрософт
* **VPS сервер** — для хостинга выделенного сервера



======

## Требования

* Unity 6000.0.56f1 или новее
* Аккаунт Google для Firebase
* VPS сервер (Linux x86\_64) или Windows машина для хостинга
* Git для клонирования репозитория

## Установка

### 1\. Клонируйте репозиторий

Установите GitHub Desktop с официального сайта (если ещё не установлен).



Войдите в свой аккаунт GitHub в программе (нажмите File -> Options -> Sign in).



Скопируйте ссылку на репозиторий:



Откройте нужный репозиторий на сайте GitHub.



Скопируйте адрес репозитория.



В GitHub Desktop нажмите File -> Clone repository.



Выберите вкладку URL (вместо GitHub.com).



Вставьте скопированную ссылку в поле Repository URL.



Выберите локальную папку на компьютере, куда сохранить проект.



Нажмите Clone.



После завершения откроется окно с файлами проекта. Теперь вы можете открыть папку через Show in Explorer и работать с кодом.Открой папку проекта через **Unity Hub** -> **Add** -> **Add project from disk**.



======

### 2\. Установи Mirror

1. В Unity открой **Window** -> **Package Manager**
2. Нажми "**+" (слева сверху)** -> **Add package from git URL**
3. Вставь ссылку ->
https://github.com/MirrorNetworking/Mirror.git
4. Нажми **Add** и дождись установки
5. После установки в проекте появится папка "Assets/Mirror"



======

### 3\. Настройка Firebase

#### 3.1 Создай проект Firebase

1. Зайди на [console.firebase.google.com](https://console.firebase.google.com)
2. Нажми **Создать проект**  введи название -> **Создать**

#### 3.2 Создай Realtime Database

1. В левом меню выбери **Build** -> **Realtime Database**
2. Нажми **Создать базу данных**
3. Регион — (Выбирайте ближайший к вам или любой на ваш выбор)
4. Режим — **Тестовый режим**
5. Скопируй URL базы (ссылка должна быть такого формата):
https://название\_вашего\_проекта-default-rtdb.europe-west1.firebasedatabase.app



#### 3.3 Правила базы данных

Зайди во вкладку **Rules** и установите:



json
{
"rules": {
".read": true,
".write": true
}
}



\-> Нажми **Опубликовать**.



#### 3.4 Вставь URL в проект

В Unity на сцене найди объекты **FirebaseManager** и **ServerListManager**. В инспекторе каждого в поле **Firebase Database URL** вставь скопированный URL из шага 3.2.

## Сборка билдов

### Серверный билд

1. Открой **File** -> **Build Settings**
2. В **Scenes In Build** ставьте главную сцену меню и все остальные которые вы планируете использовать в вашем проекте
3. Выберите платформу:

   * **Dedicated Server**  \*рекомендуется\*
   * Или **Linux** с галочкой **Server Build** для VPS
4. Нажмите **Build** и сохраните в отдельную папку



### Клиентский билд

1. Откройте **File** -> **Build Settings**
2. В **Scenes In Build** оставь теже сцены что и на сервере
3. Выберите платформу **Windows** или любую другую
4. Нажмите **Build**

## Запуск сервера на VPS

### Загрузи билд на VPS

### Открой порты на VPS

Windows CMD команда
netsh advfirewall firewall add rule name="MyPortRange" dir=in action=allow protocol=TCP localport=6000-9000

Консоль Linux
sudo ufw allow 7778/udp
sudo ufw allow 7778/tcp
sudo ufw reload



### Запусти сервер с указанием порта



\#Linux
Через командную строку введите
./No Light2.exe --port 7778

\#Windows
Через командную строку Windows введите путь к файлу в "" + команду с указанием порта для запуска --port 0000
Пример:
"C:\\Users\\Administrator\\Downloads\\D3D12\\No Light2.exe" --port 7243



После запуска сервер автоматически:

1. Получит внешний IP
2. Назначит порт и IP в KCP Transport
3. Запустит Mirror сервер
4. Запишет данные (IP, порт, статус) в Firebase



Остановка сервера

Ctrl+C или просто закройте окно консоли, при остановке сервер автоматически удалит свою запись из Firebase.

## Запуск клиента

1. Запусти клиентский билд
2. В главном меню появится список доступных серверов загруженный из Firebase
3. Нажми на сервер в списке чтобы подключиться
4. Список обновляется автоматически каждые 10 секунд или вручную кнопкой **Обновить**

## По возможным проблемам

|Проблема|Решение|
|-|-|
|Клиент не видит серверы|Проверь URL Firebase в инспекторе ServerListManager|
|Сервер не запускается|Убедись что указан аргумент "--port XXXX" при запуске|
|Не удаётся подключиться к серверу|Открой UDP порт на VPS через "ufw allow ПОРТ/udp"|
|Firebase недоступен|Смени DNS на "8.8.8.8" или используй VPN|
|У игрока не появляются доступные сервера|- Попробуйте другую сеть<br />- Исправьте настройки днс на своем устройстве<br />- Временно отключите встроенную защиту системы|



Так же по возможным проблемам можете оставлять комментарии прямо в репозитории проекта.
